# 잔야(가제) — 맛보기 (밖에서 같이 하는 판)

- 같은 주소로 들어온 사람끼리 같은 거리에서 만난다 (Claude 계정 필요 없음).
- 같이 하기 연결: 공개 MQTT 중계(broker.emqx.io 등) — 자리·레벨·별명만 오간다.
- 따로 놀고 싶으면 주소 끝에 `?room=아무글자` 를 붙여 같은 글자를 쓰는 사람끼리.
- 지도 일부: © OpenStreetMap contributors (ODbL).

## 안드로이드 앱 (APK)
- `app/` = 앱 껍데기(Capacitor). main에 게임이 올라가면 GitHub Actions(APK)가 `janya.apk`를 만들어 **Releases**에 올린다.
- 휴대폰에서 Releases의 `janya.apk`를 받아 설치(「출처를 알 수 없는 앱」 허용 필요).
